# Glass Keyboard

Клавиатура для Android в стиле «жидкого стекла»: полупрозрачная тёмная панель и скруглённые клавиши. Языки: русский и английский. Рассчитана на ColorOS 17, работает на Android 8.0 и новее.

## Возможности

- Раскладки English и Русский, переключение кнопкой `EN`/`RU`
- Страница цифр и символов (кнопка `123`)
- Shift: одно нажатие даёт одну заглавную, двойное включает Caps Lock
- Backspace с автоповтором при удержании
- Enter выполняет действие поля ввода (поиск, отправить и т. д.)
- Верхняя панель: вставка из буфера обмена и скрытие клавиатуры

## Сборка APK

Через GitHub Actions:

1. Откройте вкладку **Actions**.
2. Выберите последний запуск **Build APK** (или нажмите **Run workflow**).
3. Внизу страницы запуска, в разделе **Artifacts**, скачайте `GlassKeyboard-debug-apk`.
4. Распакуйте архив, внутри лежит `app-debug.apk`.

Через Android Studio: откройте проект и выберите Build → Build APK(s).
Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка

1. Установите APK (разрешите установку из неизвестных источников).
2. Откройте приложение Glass Keyboard и нажмите «Включить клавиатуру», затем включите Glass Keyboard в списке.
3. Нажмите «Выбрать клавиатуру» и выберите Glass Keyboard.

## Структура проекта

- `app/src/main/java/com/example/glasskeyboard/KeyboardView.kt`: отрисовка клавиатуры и обработка нажатий
- `app/src/main/java/com/example/glasskeyboard/GlassKeyboardService.kt`: сервис ввода, связь с текстовыми полями
- `app/src/main/java/com/example/glasskeyboard/MainActivity.kt`: экран с инструкцией по включению
- `.github/workflows/build.yml`: автоматическая сборка APK

## Ограничения

- Настоящего размытия фона нет: окно клавиатуры в Android не может размывать то, что находится за ним, поэтому используется полупрозрачность.
- Нет подсказок слов, предиктивного ввода и голосового ввода.
